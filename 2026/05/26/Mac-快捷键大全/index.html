Mac 快捷键大全

熟练使用 macOS 快捷键可以大幅提升日常办公和操作效率。以下为您整理的最常用、最实用的 Mac 快捷键大全，建议收藏备用。

核心修饰键符号对照

在 Mac 菜单栏中，快捷键通常以符号显示，对应键盘按键如下：

  • ⌘：Command (Cmd) 键
  • ⌥：Option (Alt) 键
  • ⌃：Control (Ctrl) 键
  • ⇧：Shift 键
  • ⇪：Caps Lock (大写锁定) 键
  • 🌐 / Fn：地球仪 / 功能键

一、 通用基础操作

这些快捷键在绝大多数文本编辑器和应用程序中完全通用。

  • ⌘ + C：拷贝（复制）
  • ⌘ + V：粘贴
  • ⌘ + Z：撤销上一步操作
  • ⌘ + ⇧ + Z：重做（反撤销）
  • ⌘ + A：全选
  • ⌘ + F：在文稿或网页中查找
  • ⌘ + S：存储（保存）当前文稿

二、 系统与窗口管理

用于快速切换应用、调整窗口或唤起系统核心功能。

  • ⌘ + 空格键：打开 Spotlight (聚焦搜索)，支持快速启动应用、计算、翻译。
  • ⌘ + Tab：在打开的应用程序之间切换（按住 ⌘ 连续按 Tab 键循环选择）。
  • ⌘ + ` (数字1左边的键)：在当前应用程序的不同窗口之间切换。
  • ⌘ + Q：彻底退出当前应用程序。
  • ⌘ + W：关闭当前窗口（应用仍保持运行）。
  • ⌘ + H：隐藏当前应用程序的窗口。
  • ⌥ + ⌘ + Esc：强制退出卡死或无响应的应用程序（相当于任务管理器）。
  • ⌃ + ⌘ + Q：立即锁定屏幕。

三、 Finder（访达）文件管理

在管理文件、浏览文件夹时必不可少的快捷组合。

  • 空格键 (Space)：快速查看 (Quick Look)，选中文件按空格可直接预览图片、视频、PDF等，无需打开应用。
  • Return 键 (回车)：选中文件后按下为重命名（Windows 中回车为打开文件）。
  • ⌘ + O：打开所选文件或文件夹。
  • ⌥ + ⌘ + V：移动文件（相当于 Windows 的“剪切”后粘贴）。在 Mac 中，需要先 ⌘ + C 复制文件，再用此组合键实现剪切效果。
  • ⌘ + ⌫ (Delete)：将所选项目移到废纸篓。
  • ⌘ + ⇧ + ⌫：清空废纸篓。
  • ⌘ + ⇧ + N：新建文件夹。
  • ⌘ + ⇧ + . (句点)：显示或隐藏隐藏文件。
  • 快速跳转特定文件夹（在访达中有效）：
  • ⌘ + ⇧ + A：前往“应用程序”
    • ⌘ + ⇧ + D：前往“桌面”
    • ⌘ + ⇧ + H：前往“个人（用户）”文件夹
    • ⌘ + ⇧ + U：前往“实用工具”
    • ⌘ + ⇧ + G：调出路径窗口，可直接输入绝对路径前往指定文件夹。

四、 屏幕截图与录制

macOS 自带非常强大的截图和录屏功能，无需安装第三方软件。

  • ⌘ + ⇧ + 3：截取整个屏幕。
  • ⌘ + ⇧ + 4：截取所选屏幕部分（按住空格键还可以捕捉特定应用程序的整个窗口）。
  • ⌘ + ⇧ + 5：打开高级“截屏与录屏”工具条，可选择录制录音、定时截图等选项。

五、 浏览器常用操作（Safari / Chrome等）

  • ⌘ + T：新建标签页。
  • ⌘ + ⇧ + T：重新打开最近关闭的标签页。
  • ⌘ + L：光标直接跳转到网址输入栏。
  • ⌘ + R：重新加载（刷新）页面。
  • ⌃ + Tab：在浏览器标签页之间向右切换。

💡 进阶小贴士：如果您想查看或修改某些特定的快捷键，可以点击屏幕左上角的 苹果菜单  > 系统设置 > 键盘 > 键盘快捷键 进行个性化自定义。
